# Add your word images here

`data/vocab.json` points at 783 files like `images/abound.png` or
`images/austere.jpeg`. Drop your image files straight into this folder using
the exact same filenames (including the extension) and they will show up on
each word's card automatically — no code changes needed.

A handful of words (about 26) have no image in the data and always show a
plain letter tile instead, and any filename that is missing or fails to load
also falls back to that letter tile — so it is safe to add images
gradually.
